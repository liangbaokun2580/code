自定义工具开发指南

您可以使用Python创建自定义工具，以扩展系统功能。每个工具都是一个独立的Python模块，需要遵循以下结构：

1. 工具元数据

在模块顶部定义以下变量：

# 工具名称
TOOL_NAME = "示例工具"

# 工具描述
TOOL_DESCRIPTION = "这是一个示例工具，用于演示自定义工具的创建方法。"

# 工具作者
TOOL_AUTHOR = "您的名字"

# 工具版本
TOOL_VERSION = "1.0"

# 工具参数定义
TOOL_PARAMETERS = [
    {
        "name": "param1",
        "type": "string",
        "label": "参数1",
        "description": "这是第一个参数",
        "required": True,
        "default": ""
    },
    {
        "name": "param2",
        "type": "number",
        "label": "参数2",
        "description": "这是第二个参数",
        "required": False,
        "default": 42
    }
]
2. 工具主函数

每个工具必须定义一个名为run的函数，该函数接收参数并返回结果：

def run(params):
    """工具的主函数，接收参数并返回结果"""
    # 获取参数
    param1 = params.get("param1", "")
    param2 = params.get("param2", 42)
    
    # 执行工具逻辑
    result = f"处理参数: {param1}, {param2}"
    
    # 返回结果（可以是任何可JSON序列化的对象）
    return {
        "message": "工具执行成功",
        "data": result
    }
3. 可用的内置模块

您可以在工具中导入和使用以下模块：

  • 标准Python库（如os, sys, json, re等）
  • 网络工具（如requests, paramiko等）
  • 数据处理（如pandas, numpy等）
安全提示： 请注意，自定义工具在服务器上执行，请确保您的代码安全可靠，不包含恶意操作。
